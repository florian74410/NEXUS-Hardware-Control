# Telemetry v1 (experimental)
Host sends JSON line type telemetry, version 1, nonce, session, seq, data with cpu usage_percent/frequency_mhz/temperature_c/temperature_source, ram used_mib/total_mib, system and reserved GPU fields. Missing values null. Touch advertises telemetry:true on hello_ack and acknowledges with telemetry_ack and matching nonce. One sample per second plus exchange time; Touch invalidates values after 3500 ms. The current CLI holds the serial port in foreground; Ctrl+C stops it. No service, automatic reconnect or IPC yet. Linux collectors only; CPU frequency is mean of reported /proc/cpuinfo clocks, RAM used is total minus available, temperature uses hwmon CPU sensor (source identifies Tctl/Tdie/package). GPU unavailable. No hardware writes.
