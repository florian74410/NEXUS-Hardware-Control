# NHC Windows x64 — preview 0.0.11
Unzip the compiled package and double-click Install-NHC.cmd. The package contains Rust Core and a self-contained .NET 8/LHM sensor helper. No developer SDK on end-user PC. Three limited-rights per-user logon tasks start immediately and on future sessions, without console windows. Core publishes snapshots, Touch rescans CH340 and authenticates NHC firmware identity, sensor helper publishes a local read-only-to-Core JSON feed. Firmware 0.1.6 unchanged.
Diagnostics: PowerShell: & "$env:LOCALAPPDATA\NEXUS-Hardware-Control\bin\nhc.exe" doctor
Uninstall: powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\NEXUS-Hardware-Control\uninstall.ps1"
Limitations: no automatic driver install; Windows Update/WCH if CH340 is missing. Limited-rights LHM sensors may be missing, especially temperatures, power and fans. No disabling Windows security or elevation of user-writable binaries. SMART, disk I/O, battery, system power are not implemented; N/A is intentional. Network includes virtual adapters; CPU frequency depends on OS reporting. No live Windows hardware validation yet. Do not distribute as stable until tests and dependencies' licenses are checked.
Developer: run Install/Windows/build.ps1 on Windows x64 with MSVC Rust and .NET 8 SDK. ZIP in dist. Build fails closed on test or compilation errors. Linux installer unchanged.
