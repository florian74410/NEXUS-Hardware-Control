# NEXUS Hardware Control (NHC)

Monorepo du système de monitoring matériel NOVA/NEXUS. Core Rust (service + CLI), Touch C++ (ESP32/LVGL), intégration Desktop NEXUS. Linux Mint, Bazzite et Windows x86_64 en priorité ; macOS et 32 bits ultérieurement.

Phases : monitoring en lecture seule, contrôle matériel sécurisé, profils. Le Core est la source de vérité. Aucun capteur additionnel obligatoire. Voir Documentation/Architecture.md.
