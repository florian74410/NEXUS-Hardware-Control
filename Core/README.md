# NHC Core 0.0.2-dev
Headless Rust CLI. Linux Mint: sudo apt install build-essential pkg-config libudev-dev; install Rust/Cargo separately. Run cargo build --manifest-path Core/Cargo.toml from repository root. Then Core/target/debug/nhc --help. Commands: status, modules list, usb scan, usb ping --port /dev/ttyUSB0, optional --json. Linux uses native tty via serialport; Windows COM backend intended but not tested. Scan does not open ports. Ping requires explicit port, may reset ESP32, and requires NHC SerialDiagnostic firmware for a valid response. Never ping during backup or flashing. No service installation yet. Core module trait is the starting point, not a completed daemon. Default output is formatted JSON in this release; terminal tables and RAW planned.
