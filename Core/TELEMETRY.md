# Core 0.0.4 — Linux collectors
All collectors are read-only, no root required by the program; kernel permissions can hide readings. Missing values null, missing sensor lists empty. CPU logical threads from proc/stat deltas. GPU DRM/sysfs (AMD best supported; proprietary Nvidia NVML/nvidia-smi not implemented; Intel usage may be absent). RAPL power is interval energy delta per domain; domains overlap and must not be summed. Battery power is separate. No total PSU measurement. hwmon sensors are raw driver-labelled, not all motherboard sensors. Storage block capacity and throughput, not filesystem free space or SMART. Network interface rates may overlap on virtual interfaces. CLI full data; USB v1 compact compatible with Touch 0.0.5, additional fields not transmitted yet. No new dependencies. Linux only. Compile and hardware validation pending.
