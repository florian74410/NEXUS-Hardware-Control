# Core 0.0.5 advanced collectors
Apple SMC: read hwmon and platform applesmc paths; no module loading or writes. i915: actual/requested clocks and RC6 cumulative residency, not GPU load. NVIDIA: optional nvidia-smi (NVML-backed CLI, not direct binding), separate array, optional timeout command. SMART: optional smartctl -j -a -n standby; read-only, may require device permissions, invoked only in one-shot snapshot, not USB sampling; ATA attributes raw, NVMe wear native. RAPL exposes inaccessible paths, no privilege escalation. Cache sensors 2s, GPU 500ms minimum interval; foreground USB still approximately 1Hz. SMART not yet periodic; no daemon. Existing Touch projection unchanged. Compile and hardware tests pending.
