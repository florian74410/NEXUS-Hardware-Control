# Core 0.0.8
User systemd service samples about once per second and publishes atomic private JSON in XDG_RUNTIME_DIR. CLI and USB use fresh cache (5s) or direct fallback. User manager may need logout/login after sensor group membership change. Extended USB projection is negotiated by hello_ack telemetry_extended:true; legacy Touch remains unchanged. Data projection selects first GPU (NVIDIA preferred), first fan, first supported disk, first active physical-looking network interface, first battery, package RAPL domains only. Full data remains in data get. No automatic USB reconnect, Windows/macOS, Intel load or native NVML yet. Tests and device validation pending.
